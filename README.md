# 책 사이 · 독서모임

홈(지금 읽는 책·함께 읽은 책·멤버), 9월 토론 기록, 10월 선정 도서와 후보 검토, 작품 책장과 지난 선정작을 읽는 정적 웹사이트입니다. 프레임워크나 빌드 과정 없이 동작합니다.

## GitHub Pages

1. 저장소 Settings → Pages로 이동합니다.
2. Build and deployment → Source에서 **Deploy from a branch**를 선택합니다.
3. Branch는 **main**, 폴더는 **/(root)**로 선택하고 저장합니다.
4. 배포가 완료되면 `https://hs321-lee.github.io/book-club/`에서 확인합니다.

개인 **private** 저장소에서 GitHub Pages를 사용하려면 **GitHub Pro**가 필요합니다. 저장소가 private이어도 Pages에 배포한 HTML·CSS·JS와 데이터는 공개됩니다. [GitHub 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## 로컬 확인

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 모든 리소스 경로는 상대 경로이며 `/book-club/` 하위 배포를 지원합니다.

## 기록 기준

- 지난 선정작: 최종 선정 도서만 사용자 제공 순서로 표시하며, 과거 모임의 토론 내용을 새로 만들지 않습니다.
- 9월: 2026년 9월 15일 모임 녹음에서 요약한 내용입니다. 직접 인용이나 개인의 원본 준비 자료로 표현하지 않습니다.
- 10월: 선정 도서와 후보 검토 메모, 마리오님의 개인 발표자료를 표시합니다. 아직 열린 모임의 토론처럼 표현하지 않습니다.
- 작품 목록: 추천·비교·추억·영화화 언급을 구별합니다. 제목 또는 영화 판본이 불확실한 작품은 확정 목록에 넣지 않습니다.
- 책 표지는 출판유통통합전산망과 서점 상품 페이지에서 확인한 실물 판본 표지입니다. 실제 모임에서 사용한 개별 판본을 의미하지는 않습니다.
- 진격의 거인은 만화 1권, 영웅문은 제1부 1권 표지를 표시합니다. 영화 항목은 한국 《용의자X》(2012)의 공식 포스터를 표시합니다. 실제 토론에서 언급한 영화 판본은 확인되지 않았으며 그 영화에 대한 추천·감상평을 새로 만들지 않습니다.
- 원본 녹음·전문, 사적인 대화 및 관계자의 개인 정보는 배포하지 않습니다.

`data.js`에서 주제, 화자별 요약, 작품 목록과 후보 메모를 수정합니다. 이후 모임은 같은 자료 기준으로 확장합니다.

## 작품 책장 자료 구조

- `works`: 매체와 작품 정체성을 기준으로 한 고유 작품 목록입니다. 원작 소설과 판본 미확인 영화화 언급은 서로 다른 항목입니다.
- `mentions`: 작품과 모임을 연결하며 `candidate`, `recommendation`, `mention` 역할을 복수로 가질 수 있습니다. 설명·출처·공개 별칭·녹음 시점을 함께 남깁니다. 동일 작품의 다른 달 언급도 별도 이력으로 추가합니다.
- `selections`: 선정 상태는 후보나 추천 이력과 별도로 기록합니다. 선정된 책도 후보 목록에 남습니다.
- `candidates`: 10월 모임의 후보 검토 당시 모습을 보존합니다. 책장의 고유 작품을 `workId`로 참조합니다.
- 책장 분류, 분야, 언급 이유와 검색은 함께 적용합니다. 작품은 역할 수와 관계없이 한 번씩 표시됩니다. 각 카드의 소개·추천 맥락에서 실제 해당 월의 토론이나 후보 메모로 이동합니다.

참여자의 공개 이름은 `participants`에서 곽정님·마리오님·앤님·모모님으로 관리합니다. 원래 이름은 공개 데이터에 저장하지 않습니다. 10월 후보 네 권은 앤님의 모임 전 추천입니다. `candidate-suggestion`은 후보 분류에 남기고, 추천한 작품 분류는 실제 토론의 `discussion`과 날짜 미상의 `remembered-recommendation`을 포함합니다. 후보 추천을 별도 추천작으로 혼동하지 않습니다.

참여자 아이콘은 모임에서 나눈 독서·게임·편지 이야기에서 영감받아 만든 작은 SVG 일러스트이며 실제 인물 사진이 아닙니다. 이름과 아이콘 경로는 `participants` 한 곳에서 바꿀 수 있습니다.

영화 포스터: [한국영상자료원](https://www.koreafilm.or.kr/library/search/video/00064794) 및 [CJ의 메인 포스터 공개 자료](https://www.newswire.co.kr/newsRead.php?no=652416) — 한국 《용의자X》, 2012년, 감독 방은진. 당시 모임의 영화화 언급은 판본 미확인으로 유지하며, 한국판 포스터 표시를 특정 판본 감상 기록으로 바꾸지 않습니다.

## 화면 동작

상단 탭은 홈·모임 기록·함께 볼 작품·지난 선정작 네 개입니다. 모임 기록 안에서 달을 고르며 가장 최근 달이 먼저 열립니다. 새 달은 `index.html`의 `.month-tabs`에 버튼과 같은 id의 섹션을 추가하고 `data.js`의 `meetings`에 등록합니다. `#october`, `#september`, `#discussion`, `#candidates` 주소는 해당 달로 바로 연결됩니다. 주소에 탭이 없으면 홈을 보여 줍니다. 홈의 숫자(함께 읽은 책·멤버 수·이어 온 개월 수)와 멤버별 선정작 추천 수는 `selectionHistory`, `participants`, `meetings`에서 자동으로 계산합니다. 추천자가 확인되지 않은 선정작은 멤버 추천 수에 넣지 않습니다.

색은 종이·잉크 기본 톤에 계절 포인트 색 하나를 더합니다. `tokens.css`의 `--color-season`(장식용 오렌지)과 `--color-accent`(본문 대비 기준을 맞춘 짙은 오렌지)만 바꾸면 계절 색이 바뀝니다.

움직임: 상단 탭 밑줄 이동, 홈 숫자 카운트업, 책장 표지가 꽂히듯 등장, 지난 선정작이 스크롤에 맞춰 등장, 표지를 누르면 같은 표지가 상세 화면으로 커지는 전환(View Transitions 지원 브라우저). 모든 움직임은 한 번만 재생되며 움직임 줄이기 설정에서는 꺼집니다.

첫 장면의 책·제목·세 사람의 시선은 각 장면에서 한 번만 등장합니다. 책장과 10월 후보의 표지·카드를 선택하면 공용 상세 영역에 큰 표지와 모든 소개 이력을 보여 줍니다. 닫기와 Escape는 원래 선택한 버튼으로 돌아가며, 검색·분류·월 전환은 상세를 닫아 이전 내용이 남지 않게 합니다. 움직임 줄이기 설정을 따르고, 애니메이션이 지원되지 않아도 내용을 즉시 표시합니다.

마리오님의 10월 개인 발표자료: [`mario/2026-10/`](https://hs321-lee.github.io/book-club/mario/2026-10/). 모임 전체 기록과 구분하며 보조 자료는 접어서 표시합니다.

2025년 7월 후보 세 권은 원래 후보 소개를 바탕으로 책장에 남깁니다. 추가로 기억한 작품은 날짜와 추천자를 추정하지 않으며, 과거 선정 도서 전체를 후보로 바꾸지 않습니다. 《컨택트》는 테드 창의 단편을 원작으로 한 2016년 영화이며 씨네큐브의 실제 포스터를 사용합니다.

지난 선정작은 14권의 표지 바둑판을 유지하며 제목 아래에 선정 모임의 연월 `(25.2)`와 추천자를 표시합니다. 추천자가 알려진 13권은 작은 캐릭터와 공개 별명으로 추천자를 표시하며, 좁은 화면에서는 날짜와 추천자가 자연스럽게 다음 줄로 이어집니다. 최초 선정작의 미확인 추천자는 생략합니다. 모모님 아이콘은 임시 별명에 맞춰 같은 SVG 화풍으로 만든 책을 든 캐릭터입니다.

《강의》·《생각에 관한 생각》·《컨택트》·《스토너》는 추천한 작품 분류에 포함합니다. 날짜·추천자를 추정해 과거 모임 기록에 연결하지 않습니다. 스토너의 추천 맥락은 2025년 7월 후보 소개의 인생 책 언급을 보존합니다.

함께 볼 작품은 PC 2열·작은 화면 1열의 가로형 카드로 표시합니다. 작은 표지 옆에 제목, 작가·매체, 분류, 한 줄 맥락을 두고, 전체 소개 이력·표지 출처·작품 검색은 큰 표지 상세보기에서 제공합니다. 분야와 검색은 바로 보이며 언급 이유는 상세 필터로 펼쳐 볼 수 있습니다.
