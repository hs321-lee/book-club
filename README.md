# 책 사이 · 독서모임

함께 읽은 책과 나눈 생각을 모으는 독서모임 기록입니다.

## 담고 있는 것

- **모임 기록:** 달별 선정작과 토론 요약입니다.
- **작품 책장:** 함께 검토하거나 이야기한 책과 영화입니다.
- **지난 선정작:** 함께 읽어 온 작품을 모았습니다.

HTML·CSS·JavaScript로 구성한 정적 웹사이트이며, 별도 빌드 과정 없이 동작합니다.

## 기록 원칙

공유된 자료를 바탕으로 기록하고, 참여자는 공개 별명으로 표시합니다. 원본 녹음·전문과 개인 정보는 공개하지 않습니다.

개발·AI 유지보수 문서는 `docs/ai/`에서 관리합니다.
